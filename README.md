# flowerdog

Сайт студии flowerdog.studio. Статика: HTML, CSS, JS без сборщика.

- Дизайн-система: `design-system.html` → `/design-system/`, правила в `docs/fds.md`.
- CSS: один вход `css/fds.css`, файлы `css/fds-*.css` по компонентам, префикс классов `fds-`.
- Деплой и превью: `deploy/README.md`, `preview/README.md`.
- Скриншоты до/после правок: `scripts/screenshots/README.md`.
