# FDS — дизайн-система flowerdog

Короткий свод правил для разработчиков и агентов. Живая документация с
примерами — страница `/design-system` (`design-system.html`), код — `css/fds*.css`.
Если документ, страница и код расходятся, прав код, а документ и страницу
нужно поправить в том же коммите.

## Правила

1. **Нет класса в системе — нет стиля на сайте.** Всё видимое собрано из
   классов и токенов FDS.
2. **Исключений нет.** Никаких селекторов по странице, клиенту, кейсу,
   `data-client-tag` или `data-page`. Нужно иначе — модификатор на одной из осей
   (ниже), и он работает в любом месте. Язык меняет только переносы слов
   (`html[data-lang="en"]` включает `hyphens: auto` в узких колонках), не размеры.
3. **Размеры как размеры одежды:** `2xs xs s m l xl`. Класс без модификатора — M.
   Новые ступени только по краям (`3xs`, `2xl`), между существующими ничего не
   вставляется: значение прижимается к ближайшей ступени.
4. **Текст — лестница:** H1, H2, H3, H4, текст, подпись. Внутри уровня один
   размер, меняется только вес.
5. **Всё от базы.** Размеры в `rem` (лестница, отступы) и `em` (внутри
   компонента). Пиксели только в формуле базы в `fds-settings.css`.
6. **Всё на `fds`:** классы `fds-`, токены `--fds-`, файлы `css/fds-*.css`,
   элементы `<fds-gallery>`. Состояния от JS без префикса: `is-*`, `has-*`.

## Имена

`fds-блок__элемент--модификатор`. Блок по смыслу, не по месту. Оси модификаторов:

| Ось | Значения | Пример |
|---|---|---|
| размер | `2xs xs s m l xl` (без модификатора M) | `fds-chip--s`, `fds-space--l` |
| вес текста | `regular medium` (только текст и подпись) | `fds-text--medium` |
| цвет | `accent` | `fds-quote--accent` |
| форма | `hard soft round` | `fds-card__cover--round` |
| только мобила | `mobile-` + размер | `fds-space--mobile-s` |

## Токены (`css/fds-tokens.css`)

**Текст.** `--fds-type-h1…h4`, `--fds-type-text`, `--fds-type-caption`, интерлиньяжи
`--fds-type-*-leading`, веса `--fds-weight-regular|medium` (400/500); жирного (700) в системе нет.

| Уровень | Десктоп | Мобила | Интерлиньяж | Класс |
|---|---|---|---|---|
| H1 | 3rem | 2.2rem | 1 | `fds-h1` |
| H2 | 2rem | 1.8rem | 1.05 | `fds-h2` |
| H3 | 1.5rem | 1.3rem | 1.15 | `fds-h3` |
| H4 | 1.25rem | 1.1rem | 1.2 | `fds-h4` |
| Текст | 1rem | 1rem | 1.3 | `fds-text` |
| Подпись | 0.75rem | 0.75rem | 1.25 | `fds-caption` |

Заголовки H1–H4 всегда medium, модификатора веса у них нет; текст и подпись
без модификатора regular. Тег по смыслу, вид
классом: название кейса — `<h1 class="fds-h2">`. Компонент не задаёт свои
размеры шрифта, только токены лестницы.

**Отступы.** `--fds-space-2xs|xs|s|m|l|xl` = 0.25 / 0.5 / 1 / 2 / 3 / 5 rem.
Спейсер `fds-space` (M), `fds-space--{размер}`, `fds-space--mobile-s`. Сетка:
`fds-grid` (4 колонки), `--2`, `--3`, `--gap-{размер}`, `--row-gap-{размер}`,
`--col-gap-{размер}`, `--keep`, `--top`; элемент `fds-grid__item`, `--l`, `--xl`.
Поле страницы `--fds-gutter`: S на десктопе, XS на мобиле.

**Отступ перед заголовком** — по ступени заголовка (по виду, не по тегу):
H1 и H2 — `fds-space--xl`, H3 — `fds-space--l`, H4 — `fds-space` (M). Группы,
которые читаются вместе, получают правило сверху, а внутри — одинаковый
отступ: теги и название кейса — `fds-space--s`; манифест, портреты и вступление
на главной — `fds-space` (M). Отступ после заголовка встроен в заголовок. Модификатор
`--mobile-s` сохраняется. Карточки, имена людей и лиды-абзацы под правило не
попадают: это не заголовки разделов.

**Скругления.** `--fds-radius-s|m|l` = 1 / 1.4 / 2 em. Отдельно `--fds-radius-pill`
(100em) — круглые концы только для маленьких элементов: плашки, кнопка,
аватары, полоска обложек; из больших — только круглая обложка.
M — обложка проекта.

**Плашки.** `fds-chip` (M), `fds-chip--s`; ряд — `fds-chips`.

**Цвет.** Палитра `--fds-blue|orange|white` и оттенки 50% и 10%; в
компонентах только смысловые токены: `--fds-text`, `--fds-text-muted`,
`--fds-accent`, `--fds-accent-muted`, `--fds-bg`, `--fds-surface`,
`--fds-surface-accent`, `--fds-line`, `--fds-inverse-bg`,
`--fds-inverse-text`, `--fds-shadow`. Синий — чернила, оранжевый — только реакция
и акцентная цитата.

**Движение.** `--fds-duration-fast` 0.2s, `--fds-duration-slow` 0.3s, одна кривая `--fds-ease`. Слои `--fds-z-*`.

## База и ширины

- Мобильная раскладка `@media (width <= 768px)`, десктоп — всё, что шире.
  Граница записывается только так.
- База: на телефоне 14px → 20px (с 469px), на десктопе 11px на 768 → 22.5px на
  1500, но не меньше 14px.
- Шапка складывается в бургер до 1024px (`css/fds-header.css`,
  `js/header-scroll.js`) — единственная своя граница у компонента.

## Как добавить новое

1. Поищи, нет ли этого в системе. Почти всегда есть.
2. Значение прижми к ступени шкалы. Новая ступень — только по краю.
3. Отличие оформи модификатором на одной оси, не правилом под место.
4. Сначала добавь на `/design-system` с примером, потом используй на странице.
5. Сравни скриншоты до и после: `scripts/screenshots/` (`node shoot.mjs <метка>`,
   `node compare.mjs <а> <б>`). Всё, что изменилось и не было согласовано, —
   ошибка.

## Файлы

`css/fds.css` — вход, каскадные слои `tokens, base, layout, text, components,
pages, utilities`. Один компонент — один файл: `fds-chip`, `fds-header`,
`fds-footer`, `fds-card`, `fds-person`, `fds-quote`, `fds-gallery`,
`fds-case`. `css/design-system.css` — только для страницы документации, префикс
`ds-`. История изменений — в git и в разделе «История» на `/design-system`.
